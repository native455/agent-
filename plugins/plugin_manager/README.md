# Plugin Manager

Version: 1.0.0

This plugin manages MyAgent plugins.

## Features

- List installed plugins
- Show plugin information
- Count installed plugins
- Reload plugins (future)
- Enable plugins (future)
- Disable plugins (future)

## Purpose

The Plugin Manager provides a central interface for discovering and managing plugins in MyAgent. It allows the core system to inspect available plugins without hardcoding them into the application.
